# GTE V7 لميتاتريدر 4

بوت (Expert Advisor) بلغة MQL4 يشتغل بنفس منطق مؤشر Gold Trend Engine V7،
مع نسخة مؤشر للعرض فقط.

```
mt4/Experts/GTE_V7_EA.mq4                  ← البوت: يرسم + ينفّذ الصفقات
mt4/Indicators/GTE_V7_Structure_Matrix.mq4 ← مؤشر عرض فقط (بدون تنفيذ)
```

---

## 1) التركيب

1. افتح ميتاتريدر 4، ثم `File` ← `Open Data Folder`.
2. انسخ `GTE_V7_EA.mq4` إلى مجلد `MQL4/Experts`.
3. انسخ `GTE_V7_Structure_Matrix.mq4` إلى مجلد `MQL4/Indicators`.
4. ارجع للمنصة واضغط بزر الفأرة الأيمن على `Navigator` ← `Refresh`
   (أو أعد تشغيل المنصة).
5. اضغط بزر الفأرة الأيمن على الملف ← `Modify` لفتحه في MetaEditor ثم `Compile` (F7).
   لازم تظهر `0 errors, 0 warnings`.
6. افتح شارت الذهب (XAUUSD أو GOLD حسب وسيطك) على فريم M1 أو M5،
   واسحب `GTE_V7_EA` على الشارت.
7. في نافذة الإعدادات ← تبويب `Common`: علّم على
   `Allow live trading` و `Allow DLL imports` غير مطلوبة.
8. تأكد أن زر `AutoTrading` في الأعلى أخضر، ولازم تشوف وجه مبتسم 🙂 في زاوية الشارت.

> **مهم:** جدول الفريمات وفلتر الفريمات يحتاج بيانات M1 عندك.
> افتح شارت M1 لنفس الرمز مرة واحدة ونزّل التاريخ (`Tools` ← `History Center`)
> لأن فريمات 3 و 10 و 25 دقيقة غير موجودة في MT4 أصلاً، والبوت يبنيها بنفسه
> من شموع الدقيقة.

---

## 2) طريقة عمل البوت

نفس محرّك المؤشر بالحرف:

1. يحدّد القمم والقيعان (Swing) بطول `SwingLength`، وتُعتمد القمة بعد إغلاق
   `SwingLength` شمعة بعدها.
2. إغلاق أعلى آخر قمة غير مكسورة = كسر بنية صاعد (BOS)، وإذا كان الاتجاه هابطاً
   قبله فهو انعكاس (CHoCH). والعكس للهابط.
3. آخر شمعة معاكسة قبل الاندفاعة = منطقة الأوردر بلوك، وترسم مستطيلاً ممتداً
   لليمين مع خط منتصف وسعر المنطقة، وتصير رمادية إذا انكسرت.
4. عند إشارة على الشمعة التي أُغلقت للتو:
   - وقف الخسارة: خلف حد الأوردر بلوك + `StopBufferPoints` نقطة، أو مسافة ATR.
   - الهدف: مضاعف مخاطرة `RewardRatio` (الافتراضي 2R).
   - حجم اللوت: يُحسب ليكون الوقف = `RiskPercent` % من رصيدك.
   - ينقل الوقف لنقطة الدخول عند `BreakEvenAtR` (افتراضي 1R).
   - يغلق الصفقة عند الإشارة المعاكسة إذا `CloseOnOpposite = true`.

كل الصفقات تحمل رقم `MagicNumber`، فالبوت لا يلمس أي صفقة فتحتها يدوياً أو
فتحها بوت ثاني.

## 3) الإعدادات المهمة

| الإعداد | الافتراضي | الشرح |
| --- | --- | --- |
| `SwingLength` | 8 | طول القمة/القاع. أصغر = إشارات أكثر |
| `ConfirmWithClose` | true | اعتماد الكسر بالإغلاق وليس بالظل |
| `ShiftOnly` | true | صفقات الانعكاس فقط (CHoCH). اجعلها false لتداول كل كسر بنية |
| `ZoneSource` | Wick | حجم المنطقة بالظلال أو بالجسم |
| `TradeEnabled` | true | اجعلها false للرسم والمراقبة بدون تنفيذ |
| `StopMode` | Zone | الوقف من المنطقة أو من ATR |
| `StopBufferPoints` | 20 | نقاط إضافية خلف المنطقة (20 = 0.20 دولار على الذهب) |
| `RewardRatio` | 2.0 | الهدف بمضاعف المخاطرة |
| `BreakEvenAtR` | 1.0 | نقل الوقف لنقطة الدخول عند 1R، و0 لتعطيلها |
| `RiskPercent` | 0.5 | نسبة المخاطرة من الرصيد لكل صفقة |
| `FixedLot` | 0 | ضع رقماً (مثل 0.05) لتثبيت اللوت وتجاهل نسبة المخاطرة |
| `MaxSpreadPoints` | 80 | تجاهل الإشارة إذا السبريد أوسع من هذا |
| `UseMtfFilter` | false | اشتراط أن فريمات 1 و 3 و 5 دقائق كلها بنفس الاتجاه |
| `UseSession` | false | التداول داخل وقت محدد فقط (بتوقيت سيرفر الوسيط) |
| `MaxTradesPerDay` | 0 | حد أقصى لعدد الصفقات في اليوم، 0 = بلا حد |
| `PanelLanguage` | Arabic | لغة جدول الاتجاه: عربي أو إنجليزي |

إعدادات مقترحة للبداية على الذهب:

- سكالبينج M1: `SwingLength = 5`، `ShiftOnly = false`، `RewardRatio = 1.5`، `RiskPercent = 0.25`.
- تداول M5: الإعدادات الافتراضية كما هي.
- محافظ: `UseMtfFilter = true` و `MaxTradesPerDay = 3`.

## 4) الباك تست في MT4

1. `View` ← `Strategy Tester`.
2. اختر `GTE_V7_EA`، الرمز XAUUSD، الفريم M5، ونموذج `Every tick`
   (أدق نموذج متاح، وضروري لأن الوقف والهدف يُحسبان داخل الشمعة).
3. نزّل تاريخ M1 من `History Center` قبل الاختبار، وإلا فجدول الفريمات
   وفلتر الفريمات سيرجعان "محايد".
4. للتحسين (`Optimization`) ابدأ بـ `SwingLength` و `RewardRatio` و `StopBufferPoints` فقط،
   ولا تحسّن كل شيء مرة واحدة حتى لا تصل إلى نتيجة مفصّلة على الماضي.

نتائج الباك تست في MT4 تختلف عن TradingView: نمذجة السبريد والتيك مختلفة،
والوقف/الهدف عندنا حقيقيان على السيرفر وليسا مجرد رسم على الشارت.

## 5) حلول المشاكل الشائعة

| المشكلة | السبب والحل |
| --- | --- |
| ما تفتح صفقات نهائياً | زر AutoTrading مطفأ، أو `Allow live trading` غير مفعّل، أو `TradeEnabled = false` |
| `OrderSend failed, error 130` | الوسيط ECN لا يقبل وقفاً مع الأمر. البوت يعيد الإرسال بدون وقف ثم يضيفه تلقائياً؛ إذا تكرر فزد `StopBufferPoints` |
| `error 134` | لا يوجد هامش كافٍ. صغّر `RiskPercent` أو `FixedLot` |
| `lot came out as zero` | مسافة الوقف كبيرة مقابل رصيدك، أو `RiskPercent` صغير جداً مقابل أصغر لوت مسموح |
| `spread too wide` في السجل | السبريد أوسع من `MaxSpreadPoints`، طبيعي في وقت الأخبار |
| الجدول يقول "محايد" لكل الفريمات | تاريخ M1 ناقص، افتح شارت M1 ونزّل البيانات |
| المستطيلات لا تظهر | `ShowZones = false`، أو `MaxDrawnSignals` صغير، أو الشارت مكبّر جداً |
| النص العربي مقطّع | حوّل `PanelLanguage` إلى `English` |

السجل الكامل لكل قرار موجود في تبويب `Experts` أسفل المنصة، ونتائج التنفيذ في `Journal`.

## 6) تنبيه

- شغّل البوت على حساب تجريبي (Demo) أسبوعاً على الأقل قبل الحساب الحقيقي.
- للعمل 24 ساعة تحتاج VPS، لأن البوت يعمل فقط وجهازك ومنصتك مفتوحان.
- البوت ينفّذ استراتيجية بنية سوق، وليس ضماناً للربح. المخاطرة الافتراضية
  0.5% لكل صفقة، ولا يُنصح برفعها.
